# 시그니처 동물의료센터 · 수의 임상 계산기

시그니처 동물의료센터 수의사를 위한 웹 기반 임상 계산기입니다. 종(개·고양이)과 체중을
상단에 한 번만 입력하면 모든 계산기에 자동으로 반영됩니다.

의존성이 없는 정적 HTML 한 파일이라 빌드 도구나 서버 없이 브라우저에서 바로 열립니다.

## 계산기 (29종)

| 분류 | 계산기 |
| --- | --- |
| 수액 · 응급 | 수액 처방, 쇼크 볼루스, 자유수분 결핍·Na 교정 속도, 칼륨 보충(Scott), 중탄산 결핍, 수혈량, 공혈 채혈량, 산소화 지표(P/F·A-a) |
| 전해질 · 산염기 | 고혈당 보정 Na, 음이온차, 혈장 삼투압·삼투압차, 알부민 보정 칼슘 |
| 약물 · 용량 | 약물 용량, 지속정주(CRI), 응급·심폐소생 약물 차트, DKA 인슐린 CRI, 체표면적·항암 용량 |
| 영양 · 일반 | 에너지 요구량·급여량, 검사 단위 변환, 나이 환산 |
| 신장 · 투석 | IRIS CKD 스테이징, IRIS AKI 등급, 투석 적정성(Kt/V·URR), 체외순환 회로 용적, 초여과 목표·UFR, CRRT 처방, 복막투석, FENa·FEK, 혈압 평가 |

## 앱으로 설치하기

배포된 주소를 브라우저로 연 뒤 설치하면 홈 화면·바탕화면에 아이콘이 생기고,
**인터넷이 끊겨도 열립니다.** 별도 스토어나 설치 파일이 필요 없습니다.

| 환경 | 설치 방법 |
| --- | --- |
| Android Chrome | 주소창 옆 설치 아이콘, 또는 메뉴 → **앱 설치** |
| iPhone·iPad Safari | 공유 버튼 → **홈 화면에 추가** |
| 데스크톱 Chrome·Edge | 주소창 오른쪽 설치 아이콘 |

설치하면 주소창 없는 전체 화면으로 뜨고, 처음 한 번 접속한 뒤에는 오프라인에서도
계산기가 그대로 동작합니다. 병원 지하나 신호가 약한 곳에서 쓸 때 유용합니다.

온라인 상태에서 열면 항상 최신 버전을 받아오고, 오프라인일 때만 저장된 버전을
사용합니다. 갱신이 안 보이면 앱을 완전히 닫았다 다시 열면 됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `vet-calculator.html` | **원본.** 계산기를 수정할 때는 이 파일만 고칩니다. Claude Artifact 게시용 조각이라 `doctype`·`head`·`body` 태그가 없습니다. |
| `index.html` | **생성 파일.** 원본을 완전한 문서로 감싸고 PWA 태그를 넣은 배포본. 직접 편집하지 마십시오. |
| `sw.js` | **생성 파일.** 오프라인 캐시를 담당하는 서비스 워커. `sw.template.js`를 고치십시오. |
| `sw.template.js` | 서비스 워커 원본. 캐시 전략을 바꿀 때 수정합니다. |
| `manifest.webmanifest` | 앱 이름·아이콘·테마색 정의 |
| `build-standalone.sh` | `index.html`과 `sw.js`를 생성하는 빌드 스크립트 |
| `make-icons.py` | 아이콘 생성기. 모양이나 색을 바꾸려면 이 파일을 고치고 실행합니다. |
| `icon-*.png`, `apple-touch-icon.png`, `favicon-*.png` | **생성 파일.** `make-icons.py`가 만듭니다. |

## 수정 후 배포

```sh
sh build-standalone.sh
git add -A && git commit -m "계산기 수정" && git push
```

`index.html`과 `sw.js`는 생성 파일이므로 반드시 빌드 스크립트를 다시 실행한 뒤
커밋해야 배포본에 반영됩니다. 빌드할 때마다 문서 해시로 캐시 이름이 바뀌므로,
설치된 앱들도 다음 실행 때 새 버전을 받아갑니다.

Vercel에 연결되어 있으면 push 시 자동으로 재배포됩니다.

> 설치 기능과 오프라인 동작은 **HTTPS에서만** 작동합니다(localhost 제외).
> 파일을 직접 열거나(`file://`) HTTP로 열면 일반 웹페이지로만 동작합니다.

## 주의

계산 결과는 담당 수의사의 임상 판단을 보조하기 위한 참고 자료입니다. 환자의 상태, 동반
질환, 투여 중인 약물에 따라 반드시 개별적으로 검증한 뒤 적용하십시오. 응급 약물 용량과
투석 처방은 투여 전 이중 확인을 권장합니다.

참조 기준: IRIS CKD Staging / AKI Grading Guidelines, Daugirdas 2세대 spKt/V,
WSAVA Global Nutrition Guidelines, RECOVER CPR Guidelines. 각 계산기의 임계값은 일반적으로
인용되는 범위이며 센터 프로토콜이 우선합니다.
